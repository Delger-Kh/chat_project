```
chat_project/

---

## Ажиллуулах заавар

### 1. Сан суулгах (зөвхөн нэг удаа)
```bash
pip install websockets
```

### 2. Сервер эхлүүлэх
```bash
python server.py
```
Дараах мессеж харагдана:
```
[Server] Сервер эхэллээ → ws://localhost:9090
[Server] index.html-ийг браузерт нээнэ үү
```

### 3. Браузерт нээх
`index.html` файлыг браузерт нээнэ (давхар дарах эсвэл VS Code → Right click → Open with Live Server).

### 4. Олон хэрэглэгчээр туршилт
`index.html`-ийг **хэд хэдэн таб**-д нээж тус бүрд өөр нэр оруулна. Нэг серверийн терминал бүгдийг зэрэг удирдана.

---

## Классуудын тайлбар

| Класс | Үүрэг |
|-------|-------|
| `ChatMessage` | Мессежийн загвар — өгөгдөл + JSON хувиргалт |
| `ChatHistory` | Сүүлийн 200 мессежийг санах ойд хадгална |
| `ChatServer` | WebSocket сервер — холболт, broadcast, түүх |

---

## Боломжууд

- Бодит цагийн мессеж (real-time)
- Чатын түүх — шинэ хэрэглэгч нэгдэхэд сүүлийн 30 мессеж автоматаар ачааллагдана
- Онлайн хэрэглэгчдийн жагсаалт
- Нэгдэх / гарах мэдэгдэл
- Enter — илгээх, Shift+Enter — шинэ мөр

---

## Техникийн мэдээлэл

- **Протокол:** WebSocket (TCP/IP дээр), порт `9090`
- **Хэл:** Python 3.10+, HTML5, JavaScript
- **Сан:** `websockets` (Python), нэмэлт JS сан шаардахгүй
